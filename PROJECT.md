# Universe War History

## 1. Идея проекта
Публичная энциклопедия канона **Universe War History**: персонажи, локации, фракции, правила мира, позже события и периоды. Автор пишет в Obsidian, сайт собирает те же markdown-файлы в читаемые страницы со связями, поиском и графом.

## 2. Целевая аудитория
Читатели вселенной, будущие игроки RPG и зрители AI-эпизодов. Сейчас — в первую очередь сам автор канона.

## 3. Проблема
Лор живёт в заметках Obsidian. Его нельзя нормально читать, шарить и переиспользовать в других проектах вселенной (AI-эпизоды, игра), пока это не сайт с устойчивыми URL и машинным экспортом.

## 4. Основной функционал MVP
- Статический сайт из vault `Universe War History`
- Страницы персонажей, локаций, фракций, правил
- Вики-ссылки `[[Сакура]]` → карточка записи
- Поиск по канону
- Граф связей
- Экспорт `/lore.json` для следующих проектов
- Черновики (`status: draft`) видны локально и помечаются бейджем

## 5. Функционал позже
- События и периоды, когда появятся заметки
- Таймлайн войн
- i18n (`/ru`, `/en`)
- Скрытие черновиков на проде (`PUBLIC_HIDE_DRAFTS=1`)
- Комментарии / теории фанатов
- RAG-обвязка канона для проекта 7

## 6. Монетизация
Сейчас нет. Позже: внимание к вселенной → эпизоды и игра.

## 7. Что уже есть
- Obsidian vault с шаблонами и первыми записями
- Сайт в `web/`: Astro + TypeScript + Tailwind
- Парсер vault, вики-ссылки, граф, поиск, `lore.json`

Запуск:

```bash
cd web
npm install
npm run dev
```

Сайт: http://localhost:4321

## 8. Что нужно сделать
1. Дописать лор (сейчас почти всё `draft`, у локаций пустой `type`)
2. Проставить вики-ссылки вместо голого текста
3. Собрать прод: `npm run build` и выложить на Cloudflare Pages / Vercel
4. Когда канон стабилизируется — скрыть черновики

## 9. Риски
- Канон ещё сырой: пустые разделы, плейсхолдеры `[[Событие ...]]`
- Имена без устойчивых id — slug строится из имени файла
- Проекты 7 и 8 начнут расходиться с сайтом, если лор копировать, а не читать vault / `lore.json`

## 10. AI-возможности
- Позже: чат по канону только из `lore.json`
- Подсказки автору: какие ссылки ещё не созданы
- Генерация эпизодов в проекте 7 строго по этому канону

## 11. Технический стек
Backend: нет (статика; канон читается на билде)
Frontend: Astro, TypeScript, Tailwind CSS v4
Database: Obsidian Markdown + YAML
Hosting: локально Astro dev; прод — Cloudflare Pages или Vercel
Bot: нет
Payments: нет
AI: нет на этом этапе
Export: `/lore.json`
